# Fontes das placas

Arquivos usados pelas placas de recepção (Painel Operacional → Placas).
Cada um é um recorte (subset) só com os caracteres latinos usados em
português, espanhol, inglês, francês, italiano e alemão — por isso são pequenos.
Todas as fontes têm licença livre, que permite embutir em PDF e distribuir.

| Arquivo | Fonte original | Licença |
|---|---|---|
| `placa-moderna.ttf` | Poppins Bold (Indian Type Foundry) | SIL Open Font License 1.1 |
| `placa-classica.ttf` | Caladea Bold (Carolina Giovanolli, Andrés Torresi / Huerta Tipográfica) | SIL Open Font License 1.1 |
| `placa-suave.ttf` | Carlito Bold (tyPoland Łukasz Dziedzic) | SIL Open Font License 1.1 |
| `placa-editorial.ttf` | Lora Bold (Cyreal) — instância estática da fonte variável | SIL Open Font License 1.1 |
| `placa-cursiva.ttf` | Lora SemiBold Italic (Cyreal) — instância estática | SIL Open Font License 1.1 |
| `placa-condensada.ttf` | DejaVu Sans Condensed Bold | Licença Bitstream Vera / DejaVu (livre) |

Texto da SIL OFL 1.1: https://openfontlicense.org — o recorte mantém os nomes
das fontes originais nos metadados, como a licença pede para versões modificadas
não serem vendidas separadamente.

para o PDF não depender de glifos compostos.
